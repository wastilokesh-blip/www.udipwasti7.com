# Udip Wasti - Culinary Professional Portfolio

A modern, professional personal website showcasing culinary expertise and professional background.

## Features

- **Professional Design** - Dark theme with elegant styling
- **Responsive Layout** - Works perfectly on desktop and mobile devices
- **Clean Typography** - Using Plus Jakarta Sans for modern appearance
- **Sections Included**
  - Professional header with title and location
  - About me section
  - Work experience
  - Education
  - Skills and expertise
  - Contact information

## Structure

- `index.html` - Complete single-file website
- `README.md` - Documentation

## Customization

All styling is contained in the HTML file within a `<style>` tag. You can easily customize:

- **Colors** - Modify CSS variables in the `:root` section
- **Content** - Update text in the respective sections
- **Contact Links** - Update LinkedIn URL or add additional contact methods

### CSS Variables

```css
--bg-color: #0f1115;          /* Main background */
--card-bg: #181b22;           /* Card background */
--accent: #f59e0b;            /* Accent color (amber) */
--text-main: #f3f4f6;         /* Primary text */
--text-muted: #9ca3af;        /* Secondary text */
--border: #272a33;            /* Border color */
```

## Deployment

### GitHub Pages
1. Go to your repository settings
2. Navigate to "Pages"
3. Select "Deploy from a branch"
4. Choose `main` branch and `/root` folder
5. Your site will be live at `https://wastilokesh-blip.github.io/www.udipwasti.com`
